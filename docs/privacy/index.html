Privacy

This preview, and the intended root site, run the calculations in your browser. Dates you type are used only to work out an age or a duration on the page you are looking at. They are not sent to a server for storage, and they are not kept once you leave the page.

The files themselves are static. A request for a page may appear in ordinary web-server logs (an IP address, a browser type, the time of the request, the address you asked for). That is normal for a public website. This preview does not set analytics cookies.

The intended address of the site is https://agecalculator.com/. This preview is not the live site; the live tool is still at app.agecalculator.com until a launch is approved. This page is a draft privacy note for the root URL, not legal advice.
